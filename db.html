설치 실패 원인, 두 줄로 확인 부탁드립니다

실패한 그 기계의 라이브 세션에서 아래 두 명령을 순서대로 실행하고 출력을 그대로 붙여 주세요.

펌웨어 모드 확인 — 결정적 단서

[ -d /sys/firmware/efi ] && echo "UEFI" || echo "BIOS (레거시) — 이것이 원인"
UEFI
펌웨어는 정상. 원인은 다른 곳에 있으니 2번 로그가 필요합니다.
BIOS (레거시)
이것이 원인입니다. 부트로더 단계에서 실패한 것으로, 펌웨어를 UEFI 모드로 바꾸면 해결됩니다.

설치 로그에서 실패 지점 추출

sudo grep -iE "traceback|error|efi|bootloader" /root/.cache/calamares/session.log | tail -30

마지막 30줄이면 충분합니다. 파일이 없다고 나오면 재부팅 없이 같은 라이브 세션에서 실행한 것이 맞는지 확인 부탁드립니다 — 로그는 재부팅 시 사라집니다.

두 출력만 있으면 펌웨어 문제인지 설치기 문제인지 바로 구분됩니다.
