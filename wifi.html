Wi-Fi Fix 스크립트 가이드

빠르고 간편하게 Wi-Fi 문제를 해결하는 스크립트 사용법입니다.

1

스크립트 다운로드

Terminal - bash 
curl -O https://raw.githubusercontent.com/nidoit/fun/main/fix_wifi.sh

💡 팁: (옵션에 사용된 것은 영문 대문자 -O이며, 원본 파일명인 fix_wifi.sh 그대로 저장하라는 의미입니다.)

2

다운로드 후 스크립트 실행 방법

만약 다운로드와 동시에 실행까지 바로 하려면 다음과 같이 할 수 있습니다.
파일을 다운로드한 후 터미널에서 실행 권한을 주고 실행해 주시면 됩니다.

1. 실행 권한 부여:

Terminal - bash 
chmod +x fix_wifi.sh

2. 스크립트 실행:

Terminal - bash 
./fix_wifi.sh
